# Olko React Style Overview

Checks React/TypeScript style for changed `.ts`/`.tsx` files with marketplace defaults: naming, formatting, imports, component patterns, hooks rules, CSS Modules, React Query, React Hook Form, and typed API client style. Runs documented format/lint commands (ESLint/Prettier) when configured. Use before commit/test gates or when delegated by olko-commit-style.

Load `SKILL.md` for the canonical workflow and rule list.
