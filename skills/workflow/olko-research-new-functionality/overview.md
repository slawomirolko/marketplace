# olko-research-new-functionality

## Overview

Research a proposed functionality from current repository evidence and return a decision-quality report. The skill traces the live mechanism, maps the current flow with `file:line` evidence, compares architecture patterns, estimates measurable impact, and designs the smallest coherent integration.

## When to use

- The user asks to analyze, evaluate, scope, or design a new cross-cutting feature before implementation.
- A decision is needed on whether and how to build a feature.

## Prerequisites

- A readable repository with `AGENTS.md` and slice-level conventions.
- `rg` available for source search.
- Read-only intent: no production code changes unless explicitly requested.
