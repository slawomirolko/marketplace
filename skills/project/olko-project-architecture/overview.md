# Olko Project Architecture Overview

Checks whole-monorepo architecture with marketplace defaults: top-level separation, DDD module layering, dependency direction, workspace package ownership, shared-code boundaries, and independent buildability. Includes React Native workspace checks for dependency duplication, Metro, native linking, and app roots. Delegates the `ai/` subtree to `olko-ai-architecture` when declared in `uses`. Use during plan review, onboarding a surface/module, or standalone.
